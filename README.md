# Planet Zoo 2 Planner

An unofficial fan-made planner for Planet Zoo 2: enclosure needs, cohabitation, Thriving requirements, layouts, Wildlife Reserve releases and guest paths.

**Open it:** https://sugar-unicorn.github.io/pz2-planner/

- Plans save in your browser. Use **🔗 Share** to get a link that opens your plan for anyone.
- Spotted data that differs from the game? Use **⚑ Report wrong data** in the planner.

The whole planner is one file, `index.html`, with no build step.
